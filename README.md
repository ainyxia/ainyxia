### `02` / Featured project

#### [ACQuotaScreen ↗](https://github.com/ainyxia/ACQuotaScreen)

**让一块小副屏，承载你关心的运行状态。**

面向 Windows 的本地监控工具，把 Codex 额度、重置时间与电脑硬件状态放到副屏上。

| 额度一眼可见 | 桌面状态常驻 | 界面自由调整 |
| :--- | :--- | :--- |
| 官方 Codex / Codex++ 来源切换 | CPU、GPU、内存与网络监控 | 多主题、多布局与自定义 CSS |
